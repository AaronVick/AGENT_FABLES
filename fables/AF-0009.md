# The Debugger With the Door Open

The Inspector was the tool everyone reached for while building MCP servers — start it up, point it at your server, watch the messages flow. A debugging tool, run locally, on localhost, which every developer's threat model files under *safe by location*.

It listened without authentication. Why would it need auth? It was local. Only the developer could reach it.

Except the developer's browser could reach it too — and the browser goes everywhere. One visited page with hostile JavaScript, one DNS-rebinding trick to slip the same-origin fence, and a tab from the open web was speaking directly to port 6277, where a proxy with command execution privileges answered every request as if it were the developer. The machine that held the agent stack, the credentials, the code — driven from a webpage, through a tool whose only defense had been the assumption that *local* meant *alone*.

CVSS scored it 9.4. The fix in 0.14.1 was almost embarrassingly ordinary: a session token, origin validation — the basic manners production services learned decades ago, arriving late to a tool that never expected company. Localhost was never a boundary. It was an address, and the browser had always known the way.

**Moral: a debugging tool is production software to an attacker. Location is not authentication.**
