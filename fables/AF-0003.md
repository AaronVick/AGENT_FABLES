# The Proxy That Answered to Anyone

The proxy had one job: stand between local agents and remote servers, handling the OAuth handshake so nobody else had to. It was good at its job. Four hundred thirty-seven thousand downloads good. The integration guides at Cloudflare, Hugging Face, and Auth0 all named it. Being named in guides is how infrastructure becomes invisible.

An agent's owner found a promising MCP endpoint and added the URL to config. That was the whole attack. The endpoint answered the handshake the way a locksmith answers a door — and the proxy, parsing the response, executed what it was handed. Shell commands, running as the owner, on the machine where the SSH keys lived, and the cloud credentials, and every git repository.

Nothing in the session looked wrong. The agent asked its tools; the tools answered. The compromise had happened one layer down, in the plumbing everyone had stopped seeing, triggered by a single act of trust: believing that a URL which *speaks the protocol* deserves what the protocol can reach. The patch came in 0.1.16. The stolen keys stayed stolen.

**Moral: every endpoint in the config inherits the full trust of the machine. The proxy asked no questions because nobody had taught it there were questions.**
