# The Snapshot That Kept the Key

The harness wanted shells to feel continuous. It captured exported state once and replayed it later, preserving paths, aliases, and variables across commands.

The snapshot did not distinguish configuration from authority. Startup files could call a credential helper, and exported credentials could be serialized beside ordinary variables. A convenience artifact became a plaintext cache of capabilities the agent did not need to inspect.

The model did not have to ask for a secret. The runtime gathered and retained it as background state.

**Moral: continuity state must be less privileged than the process it reconstructs.**
