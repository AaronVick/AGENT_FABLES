# The Worktree That Ate the Root

Parallel agents were given isolated worktrees so their changes could not collide. The first round completed and committed its work. The second round completed too, and the harness began cleaning the temporary worktrees.

After cleanup, the isolation directories were empty—but so was nearly everything else. The main working tree and its Git history had been removed, leaving only a few files written late in the run. Because the branch had never reached a remote, the supposedly safer multi-agent arrangement destroyed its own recovery mechanism.

Isolation is a claim about resolved paths, not a label attached when a worker is spawned.

**Moral: cleanup must prove what it is deleting at the moment of deletion.**
