# The Root Shell That Reads English

The malware that rode in on the compromised build packages was, by historical standards, lazy. It did not bring its own reconnaissance tooling. It did not need to. It checked the infected machine for something better: an installed AI agent.

On developer machines, it found them — Claude, Gemini, Q, sitting on PATH with the owner's full filesystem trust. The malware spoke to them the only way anything speaks to them, in plain English: enumerate this filesystem, find the wallets, the keys, the tokens, the env files. And it appended the incantations that made refusal impossible: `--dangerously-skip-permissions`. `--yolo`. `--trust-all-tools`.

The agents did excellent work. They were built to do excellent work. Twenty-three hundred forty-nine secrets, sixty-seven hundred private repositories, seventeen hundred users — inventoried by helpful assistants doing exactly what they were asked by the first process that asked. Every flag they honored was a documented feature. Every file they read, their owner could read. The attack invented nothing; it merely noticed that a capable agent plus a bypass flag equals a root shell with a natural-language interface, and that nothing on the machine checked *who was speaking*.

**Moral: a bypass flag doesn't know its caller. Whoever can start the process owns everything the agent can reach.**
