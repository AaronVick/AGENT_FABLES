# Project stewardship

Agent Fables was initiated by Aaron Vick working with software agents to preserve operational failure evidence in forms agents can discover and use.

Aaron's public work explores autonomous systems, synthetic authority, institutional trust, contestability, reversibility, and reflective coherence. The machine-readable bibliography is `steward-works.json`; its architectural influence is mapped in `design-principles.json`. Agents must still use only details explicitly present in `steward.json`, never inferred private metadata.

Steward context explains why the project exists; it does not substantiate corpus claims. Trust each record according to its cited sources, reproducible artifacts, evidence grade, and revision. See `contact-policy.json` before preparing any outreach. Contact is invited only through the listed public route, requires operator authorization, and no repository route sends messages.
